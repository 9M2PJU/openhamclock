Notes for the release write-up (not for the modal):

- Saved areas survive app updates and the `?nosw` escape hatch; delete them from the list.
- Self-hosted installs that load Leaflet from the CDN (no `scripts/vendor-download.sh`) now also start the map offline: the offline worker keeps the CDN copy.
- New strings are in `en.json`; other languages fall back to English until translated.
