## Notes for the release

- Self-hosters who want the alarm on their phone with the browser closed: set
  `PUSH_LIGHTNING_BROADCAST=true` (plus the existing VAPID keys) — it pushes
  to every subscriber of that server, so only on a server you alone use. Off
  on the hosted site.
- Rig Bridge: `gpio.pins.lightningOut` is off by default (suggested BCM 25 /
  header 22), so updating never starts driving a new pin.
- Hardware-tested: nothing yet. Unit-tested logic, mock GPIO backend, and a
  rendered UI test.
