# P2 — What's New draft (shared incident)

Paste into the release's `features` array in `src/components/WhatsNew.jsx`:

```js
{
  icon: '🤝',
  title: 'NEW: Shared Incident for EmComm',
  desc: 'A new Incident panel at the top of the EmComm rail lets several operators and sites work one operating picture. One station creates the incident and shares its id and key (read them over the air, or scan the QR code with a phone). Every joined browser then sees the same Net Roster, Event Log, field and shelter reports, ICS form drafts, running Net Control net and incident board, with each entry tagged by site and new events arriving live. The creator holds an admin key that can correct or delete entries and issue a new join key if one leaks. Two sites working the same net at once keep both sets of changes, and when both changed the same station a "your change" chip puts yours back in one click. ICS form edits made offline never overwrite someone else's newer version: you see theirs, the differences, and Apply mine. If the connection drops, updates wait in the browser and go out when it returns, and leaving restores everything the browser had before.',
},
```
