# P2 — What's New draft (shared incident)

Paste into the release's `features` array in `src/components/WhatsNew.jsx`:

```js
{
  icon: '🤝',
  title: 'NEW: Shared Incident for EmComm',
  desc: 'A new Incident panel at the top of the EmComm rail lets several operators and sites work one operating picture. One station creates the incident and shares its id and key (read them over the air, or scan the QR code with a phone). Every joined browser then sees the same Net Roster, Event Log, field and shelter reports and incident board (name, IC, net frequency, notes), with each entry tagged by site and new events arriving live. Voice check-ins and check-outs go straight into the shared roster. If the connection drops, updates queue in the browser and go out when it returns. The server keeps the incident through a restart, and leaving returns the browser to its local-only log.',
},
```

Manual: docs/MANUAL.md → The EmComm layout → "Shared incident: one picture for several operators and sites". API: docs/API.md#shared-incident-api.
