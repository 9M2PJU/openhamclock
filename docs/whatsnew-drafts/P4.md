Shorter variants (if the list is tight):

> **NEW: NBEMS (fldigi + flmsg)** — fldigi's mode, frequency, receive text and a send box in the EmComm layout (locally or through the Cloud Relay), ICS-213 sending through fldigi, and received flmsg forms, compressed or not, in Field Reports. Rig Bridge → Plugins → fldigi + flmsg.

> **Cloud Relay commands are signed** — a key shared only between your browser and Rig Bridge; reconnect the Cloud Relay once in Settings → Rig Bridge to get one.
